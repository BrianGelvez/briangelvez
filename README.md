## ` 01 ` Sobre mí

```ts
const brian = {
  role: "Full Stack Developer",
  location: "Córdoba, Argentina 🇦🇷",
  focus: ["Next.js", "TypeScript", "Node.js", "PostgreSQL"],
  background: "Ex Ejército Argentino · Cía Comando 602 · Paracaidista",
  building: "Productos reales con usuarios reales",
  philosophy: "Disciplina aplicada a software que funciona",
};
```

Soy **desarrollador full stack** especializado en construir **aplicaciones web modernas, escalables y mantenibles** con el ecosistema **Next.js + TypeScript**. Vengo de un camino poco lineal: cuatro años como **soldado voluntario en el Regimiento de Infantería Paracaidista 2 (Córdoba)**, luego una reconversión profesional autodidacta durante la pandemia y el bootcamp **Soy Henry**, y desde 2023 trabajando en **producto real** — desde una academia online SaaS en Brasil hasta sistemas internos y chatbots en producción para una cooperativa eléctrica con +2.500 socios.

Lo que llevo de esa primera etapa: **disciplina, criterio operativo y la capacidad de mantener la cabeza fría cuando el contexto se complica**. Lo aplico a producto: código claro, decisiones técnicas justificadas y entregas que se sostienen en el tiempo.

> _"Soldado por formación. Developer por decisión."_
